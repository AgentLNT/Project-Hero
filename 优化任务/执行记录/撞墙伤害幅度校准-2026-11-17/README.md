# 撞墙伤害幅度校准

2026-11-17 开始，2026-11-18 补跑对照。

逐格位移和撞墙 1∶1 照常结算。本轮没有找到适合纳入正式配置的数值。抗冲击 20、25 的墙边结束率高，却经常在一方首窗前结束；能避免这种提前出局的低档，两组速度都仍有不少对局拖过观察上限。

在 HP50 和现有直伤下，只要一次攻击的直伤为 D，任何能尝试撞墙的剩余动量就至少是目标抗冲击 R；贴墙时的合计伤害至少为 **D + R**。所以重砸直伤 40 时，R ≥ 10 的目标只要被单次重砸推撞墙，满血也会阵亡。按原重砸动量 1.6R 缩放，未量化的理论门槛是 R < 6.25。

## 固定脚本

两个基准均为 HP50。分别使用行动速度 20／移动速度 30、行动速度 24／移动速度 20。五招保持直伤 15／25／20／40／30；等比例档的五招动量为 0.48R／0.30R／0.72R／1.60R／1.50R。额外测试重砸、旋风斩分别为 2.5R、2.2R 的两格档，以及 R9 时只将重砸动量压到 9.75 的一格档。

表里的额外伤害是尚未按剩余生命封顶的名义墙伤。无格挡、目标满血。

| 参数 | 快斩／直刺／横扫／重砸／旋风斩动量 | 重砸贴墙：墙伤 → 剩余 HP | 旋风斩贴墙：墙伤 → 剩余 HP |
| --- | --- | ---: | ---: |
| R6，原比例 | 2.88／1.8／4.32／9.6／9 | 9.6 → 0.4 | 9 → 11 |
| R9，重砸减动量 | 4.32／2.7／6.48／9.75／13.5 | 9.75 → 0.25 | 13.5 → 6.5 |
| R12.5，原比例 | 6／3.75／9／20／18.75 | 20 → 0 | 18.75 → 1.25 |
| R20，原比例 | 9.6／6／14.4／32／30 | 32 → 0 | 30 → 0 |
| R25，原比例 | 12／7.5／18／40／37.5 | 40 → 0 | 37.5 → 0 |
| R20，两格 | 9.6／6／14.4／50／44 | 50 → 0 | 44 → 0 |

- 等比例重砸和旋风斩都能推一格；若先成功移动一格，剩余动量不足 R，墙再近也不会结算第二次尝试。R9 的重砸仍超过位移和硬直门槛，但低于原来可触发击倒的 1.5R；旋风斩仍为 1.5R。
- R20 两格档先成功一格才撞墙时，重砸和旋风斩分别结算 30／24 点名义墙伤。测试的 50% Guard 会阻止等比例档强制位移；两格档的两招被 Guard 后仍可推一格。贴墙时格挡重砸扣 20 直伤和 25 墙伤，剩 5 HP；若两格档提高到 R25，格挡重砸仍可打出 20 + 31.25，足以击杀。
- 直线每格耗时在两组速度分别为 8／12 Tick，撞第一格墙伤在命中后 8／12 Tick；第二格才撞墙则为 16／24 Tick。

## 对局口径

复用同一导出场景和当前的逐格位移战斗逻辑。无新增墙场景横跨近、中、远三档；墙边压力场景用近距，分别在双方身后紧邻单位体积放一排墙，直接暴露一个可被撞上的方向。两种速度分别取三种 AI 的 9 个有序配对和两次镜像，固定输入种子 31/4；禁用等待评分和固定施压奖励，沿用格挡／闪避费用 3/2。每档无新增墙 108 场，墙边 36 场。墙边样本是压力测试，命中频率不能代表正式地图。

“两窗致命”统计的是一方在自己的第二个行动窗结束前累计对对手实际扣满 50 HP，且本场已经自然结束。若该方只开过一个窗口就终结战斗，也计入；另列未开过首窗就死亡的场次，避免把抢在对手获得机会前击杀当作健康节奏。720 Tick 未结束记为未达标；同时保存每方窗口数、个人截止点和实际扣血。这个一对一口径不证明多人战的个人两窗节奏。

## 拼刀的额外变量

本轮换算保持了多数动作的动量／抗冲击比，但拼刀的旧残余伤害读绝对内部动量并向下取整。用重砸和直刺正面对冲，在求解器探针中，R1000、R25、R20、R12.5、R6、R9 重砸减动量的旧残余伤害分别为 130、3、2、1、0、0。它是探针里传给伤害通道的原始量。正式命中仍要经过伤害通道、抵抗和 HP 封顶；对局中两档即使没有撞墙也出现行为差异，本轮没有单独鉴别每一场差异是否由残余伤害造成。后续若要维持原节奏，应把旧拼刀伤害的标度单独列为变量。

## 继续校准的边界

如果希望常规重砸保留击倒，同时满血目标贴墙时仍能活下来，首格就撞墙的条件是 **直伤 + 入墙时剩余动量 < 目标满生命**。在本轮 HP50、抗冲击 12.5 的独立定义里，保留重砸 20 动量就要求直伤低于 30。此前提到的 28 只用于说明 `28 + 20 = 48` 这个边界，不作为后续默认试验或正式定值；它会单独改变重砸的伤害与动量比例。

这个旧场景样本也无法靠统一缩放重砸同时满足两条要求：将原来的 40 直伤和 20 动量一并乘以同一系数，保留击倒要求系数至少为 `18.75 / 20 = 0.9375`，避开满血一击则要求小于 `50 / 60 ≈ 0.8333`。这是这一组旧参照的矛盾，不能据此改写三类通用配方。

后续比较以 [v0.5 三类公共配方](../../../设计文档/战斗测试/人物属性与战斗数值完整方案-v0.5-2026-10-23.md)为约束：同等招式强度下，穿刺、挥砍、钝击的直伤／动量分别为 5／1、4／3、3／5。先比较同强度、同防御条件下三类攻击在无墙、贴墙、拼刀时各自得到什么，并同时记录两窗致命和首窗前阵亡。若只有个别招式异常，先检查强度、时序、范围和使用条件。若一整类在不同局面都出现同样的问题，再讨论公共配方是否需要调整。
