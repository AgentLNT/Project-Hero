## 已实现

- 战术暂停下可在时间轴刻度条点击或拖动时间游标；按钮及左右方向键每次微调 0.1 秒，Home 或“回到当前”恢复跟随。观察态跟随当前时间，系统暂停、结束和恢复选择框有输入门禁。输入框和反应放置滑条获得焦点时不会被方向键游标快捷键抢占。
- 新增 Logic `PreviewSpace`，返回控制者过滤后的计划位置、单位朝向、占位、我方路径和公开攻击范围。位置严格在 MovementSegment.EndTick 提交，不把插值坐标当作逻辑位置；已公开移动完成后在视界内保留计划落点。单位占位朝向沿用权威 Facing，动作的瞄准方向只用于其攻击范围，不把攻击方向误当作单位旋转。
- 我方残影使用半透明占位和朝向箭头，路径使用线段；攻击范围使用描边并带文字。我方可查看自己的草稿，敌方 Editable 计划不进入投影。视界外的他方单位保留当前已提交位置并标“未知”；无公开计划的未来也不推测。游标最多查看当前之后 3600 Tick，几何缓存最多保留 64 个时刻。
- 残影展示计划几何，不展示伤害或击退后的结果。时间轴和战场接触标记共用 Logic 的接触对象，点击后聚焦同一时刻并补充相关轨道，保留主选和其他草稿。检查未来时刻会收起反应卡以让出战场；回到当前恢复卡片。
- C2 的“先移动、后攻击”已联动：指向范围原点、点击选向和目标占位都读取 Logic 的候选起点投影。悬停范围与已点击配置分别显示；已点击配置在鼠标离开战场后继续保留，不会因为悬停清理而消失。加入草稿后交由游标显示草稿范围。
- 配置器读取 `PreviewSpatialResults`：预计接触结果、伤害、击退停止格、实际/请求步数及边界、障碍、单位或同批冲突原因。结果复用过滤世界的正式 Step、全局同时位移求解器和实际事件；击退来源仅取实际传入动量和拼刀剩余冲击，不由 UI 根据范围颜色推断命中或位移。
- 新增独立诊断层，Editor/Development 可用 F3 或按钮折叠，显示 Tick、修订、视界、主选和原始拒绝码。提供 100%～130% 字号和高对比设置；按钮、输入框和滑条保留可识别的背景，信息同时使用形状与文字，战场标签会避让其他标签和威胁标记。

## 发现与修复

1. 原有只读世界未复制正式位移求解器的静态障碍输入。新增内部几何复制接缝，复制公开障碍点集，不共享网格、求解器实例或诊断计数器。当前示例 Encounter 没有地形障碍的 Authoring 来源；本次没有新增地形编辑或改变默认场景规则。障碍用例明确配置既有正式求解器的静态几何，然后同时验证预告和真实 Step 的停止格与停止原因。
2. M3 自动选中但资源不足的反应候选会污染整份组合预览，导致公开攻击范围消失。不可行候选现在保留卡片禁用原因，但不加入组合预览；可行候选、暂存反应和待采纳反应仍沿用既有顺序。
3. 场景销毁时相机可能先于宿主释放。M4 刷新对相机和显示对象增加释放门禁，重复释放及跨场景重开保持安全。
4. 新增的已公开移动用例首轮使用了被单位体积阻挡的非法落点，命令被正确拒绝；夹具改为合法 `(6,2)`，保留真实命令接受断言，没有放宽寻路规则。

Logic 接口：`HudPreviewService.PreviewSpace / PreviewPlanningStart / PreviewSpatialResults`。View 接口：`BattlePresentationView.SpatialView / ConfiguredAttack / SpaceOperations`；`M4SpatialView.SetCursor / Nudge / ReturnToNow / SelectContact`。
