# 短组合规划与有效施压

2026-11-13 开始，2026-11-14 完成首轮实施与对照。承接用户确认的“走 N 步放技能 B，统一评分”方案，任务包见[任务23](../../23-短组合规划与有效施压.md)。

实现了可选短组合规划，正式内容对照证明接近、有效施压和防御消耗增加；**超时仍为52/54，不采用正式默认配置，不宣称整体行为验收通过**。这是一组人工设计模板和公开内核预演，没有训练过程、学习权重或隐式语言意图。

## 代码与执行方式

改动位于 AI 的候选生成和预演评分层。复用生产 A*、命令入口、排程、窗口、伤害和防御规则，没有另写战斗模型。

- 直接攻击：保留现有攻击候选，区分“命令合法”和“是否产生战术效果”。
- 移动后攻击：用规范攻击三角形反推少量攻击位置，以生产寻路取最多4条边的移动前缀，再预演等待合规窗口和后续攻击的整段结果。后续提交遵循6 Tick思考间隔。
- 阶段性接近：整段攻击超出范围或无完整收益时，另列出已完成移动、且真实距离与目标路径均有进展的 Approach 候选。完整组合的拒绝/未覆盖记录仍保留。
- 等待和防御：显式无命令基线；反应仍走任务22独立采样池和重抽记忆。无伤害但有打断、拼刀、避伤或敌方位移的候选仍可评分、采样。

**真实执行只提交第一步。** 第一步到真实终态后，在下一次可思考时点按当前公开局势重选。预演中的技能 B 不会预先塞入权威排程；实战可以换技能、继续移动或防御。没有在权威快照外保存“待执行的第二条命令”。

主要源码：`AiShortPlanSettings.cs`、`AiShortPlanCandidateBuilder.cs`、`AiShortPlan.cs`、`AiPressurePolicy.cs`、`AiForecastWorld.cs`；生产寻路计算器新增只读路径端口。实验与证据工具分别为 `AiPolicyExperiment`、`ShortPlanMatchupTools`、`ShortPlanNativeValidation`。

## 配置与评分

`AiForecastSettings.ShortPlans` 默认为空。开启时需同时启用 Sampling；本轮使用：

```csharp
new AiForecastSettings(360, true, true,
    new AiSamplingSettings(SignedDamage: true, HealthDefense: true),
    new AiShortPlanSettings());
```

协议 `short-plan-public-kernel-v1`；最多4条移动边、每招2个目标落点、最多24个路径探测。只考虑目标最近的3个体积三角形和3个接近朝向，**不是穷举所有路径或所有两步组合**。参数、协议和分组方式均进入定义哈希。

评分保留原有伤害、防御、受伤、位置、打断、拼刀、资源及完整占用时间项，另显式增加：

- 有效施压值：无防御对照中每个实际失血敌人增加 `65536 × 该偏好的伤害权重`，相当于64 HP的评分值。它是人工设置的策略奖励，不是额外造成的伤害。对可反应目标的负伤害排序仍保留。
- 阶段性接近值：`16384 × 本段路径权重进展 / 初始路径权重`。
- 无战术效果的空挥/闲置Guard退出战术采样池，记录 `NO_TACTICAL_EFFECT`，仍标记逻辑合法。未恢复“只选正分”的门槛。

因此本轮是“模板规划 + 候选资格修正 + 显式施压奖励”的组合变化，**不能把全部收益归因于多步预演一项**。没有做奖励值消融、参数择优、额外种子扩围或平衡定值。

## 第一步与后续实战

共选中775次有目标移动：725次 MoveAttack、50次 Approach。775次均真实启动，759次完成，16次在观察截止仍活动。

749次观察到了后续普通动作，其中561次紧接着攻击；265次使用预演提出的技能，296次换成了其他攻击技能。561次紧接攻击中158次实际造成正伤害。其余后续动作包括继续移动、Guard等；26次在截止前未观察到下一普通动作。

这些数字表明移动有后续用途，也表明它采用逐步重规划，不能宣称775套预写连招都按脚本完成。`continuations.json` 保留第一步、终态、预测技能、下一真实动作及首次后续攻击；“最终跟过攻击”的统计会在多段移动之间重叠，不当作独立连招成功数。

## 采用结论与剩余问题

短组合基础能力已实施，零效果空挥采样和无法有效接近的问题明显改善。正式默认配置保持原值，本轮只提供实验开关。

超时率仍高，实战预测损失仍大。下一轮应优先用“接近后为什么没有实际造成伤害”的逐事件样本区分防御、目标移动、打断和重规划换招，再对持续投入、风险与资源交换做独立对照。不能通过禁止跨窗或宣称出现了自组织意图来跳过这些问题。
