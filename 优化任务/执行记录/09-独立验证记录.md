### 7.1 一条必须写进交接的**基础设施**教训（不是代码问题）

有一次 Unity 跑批以 `Scripts have compiler errors` 退出，但 `Logs/Editor.log` 里**一条 `error CS` 都没有**。真因：
```
ILPPTrigger: Can't find file \\.\pipe\unity-ilpp-6cd89d13320b31d333fa7c48cb310c34
*** Tundra build failed (30.27 seconds), 2 items updated, 1130 evaluated
Scripts have compiler errors.
[ExitDontLaunchBugReporter] Exiting without the bug reporter. Application will exit with return code 1
```
⇒ Unity 的 **IL 后处理（ILPP）走命名管道**；管道握手失败会让 Tundra 构建整体失败，并把结果**伪装成"脚本编译错误"**。
**判据**：看到 "Scripts have compiler errors" 却**没有任何 `error CS`** ⇒ 先怀疑 ILPP 管道，**不要先怀疑代码**；**重跑即好**（本条实测：重跑后立刻拿到 `20/18/2` 的真实结果）。
**影响修正**：主理人在此前若干轮里曾把这类失败归因于"代理在途编辑"；其中**至少一部分**其实是这个基础设施问题。凡在本记录中标注"被在途红灯阻断"的跑批，都应视为**两种可能并存**：真实 `error CS`（可在 `Editor.log`/`Editor-prev.log` 中逐字核到）或 ILPP 管道失败（无 `error CS`）。
