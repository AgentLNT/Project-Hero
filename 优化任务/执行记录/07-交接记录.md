## 已实现

### 1. 窗口系统（`Logic/Turns/**`，新增）
- `TurnWindow`：只持有整数 Tick 预算账本（`Total/Reserved/Spent/Available` + 按 `ActionPlanId` 的预留明细、
  打开状态、是否接受提交、关闭原因）。**不含** ActionPlan/Intent/Reservation 集合（有反射用例钉死）。
- `TurnWindowManager`：稳定顺序 `PlayerFirst -> ActionSpeed 降序 -> UnitId`；打开、请求关闭、Tick 末正式关闭；
  **新窗口最早下一 Tick 打开**（`LastClosedAtTick` 执行该规则）；拥有者死亡跳过；战斗结束关闭并清空未来排程；
  `FindWindow(WindowId)` 让已关闭窗口账本继续可审计。
- 关闭原因：`OwnerRequested / BattleEnded / OwnerDied / BudgetExhausted`，各有稳定文本码。

### 2. 预算事务（`Logic/Turns/ScheduleBudget.cs` 新增 + `Logic/Timeline/ScheduleEditor.cs` 接入）
- 冻结接缝：`ScheduleBudgetContext`、`ITurnBudgetAuthority`（校验/应用/回滚三段式）、
  `TurnBudgetChangeRequest`、`TurnWindowBudgetAuthority`（同时实现 `IActionPlanStartCommitPort`）。
- `ScheduleEditor.BudgetContextFactory`（来源、Tick、`ExpectedWindowId`、`Issuer`），
  `Apply(...)` 追加可选尾参 `expectedWindowId` / `issuer`（既有调用点源兼容）。
- 提交路径：求值前捕获旧预留 → 校验（授权仅对显式命令 → 预算）→ 空间端口 → 应用预算 →
  写入段 try/catch（失败 `RollbackBudget` + 恢复投影 + 重抛）。**任一步失败 = 零局部写入**。
- 系统自动延期：`SystemAutoDeferral` 来源，保持 Editable/Reserved，差额与排程/空间同批原子；
  失败回滚延期计数 + 投影 + 预算；**不要求发行者授权**（它不是玩家提交）。

### 3. 并发提交授权（`Logic/Turns/ConcurrentActionSystem.cs` 新增）
- 激活顺序：能力配置 → 主角 → 控制权 → 当前窗口 → `ExpectedWindowId` → 非拥有者 → 未激活 → 权威费用消费；
  任一步失败零副作用（不扣局外资源、不留授权）。费用只来自权威 `ConcurrentActionDefinition`。
- 窗口命令入口：`ActionPlanCommandProcessor.WindowCommandHandler` + `BattleSimulation.HandleWindowCommand`
  （身份取 `CommandEnvelope.ControllerId`，窗口取 `WindowCommandScope.ExpectedWindowId`）。
- **不授权 Block/Dodge**（并发授权只覆盖 Attack/Guard/Move）。

### 4. 肾上腺素账本（`Logic/Resources/AdrenalineLedger.cs` + `AdrenalineLedgerRegistry.cs` 新增）
- 每单位一份：`AvailableAdrenaline` 不衰减、跨其他单位窗口保留；自己窗口打开先递增 `CycleId` 再清零；
  接受反应 `Available -> 计划预留（带 ReservationCycleId）`、TriggerTick 消费；
  来源取消按"仍属当前周期才返还、跨周期只删除"；接受/触发/清理全部幂等。
- Tick 末**唯一**入账入口 `ApplyTickEndAccrual(IReadOnlyList<AdrenalineAccrualFacts>)`：
  只接受任务 08 规范聚合事实，拒绝乱序/重复键，按 `AdrenalineRules` 量化并裁到周期上限（裁剪不动预留）。
- 反应接线：`ReactionOpportunitySystem.AdrenalinePort = _adrenaline`（接受预留 + 触发消费 + 来源取消返还）。

### 5. 终态、事件与快照
