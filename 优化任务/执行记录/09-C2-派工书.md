## 3. 本轮范围

### 3.1 产出 16：Shadow 真实请求镜像

- Shadow 新模拟使用**独立逻辑世界**（不变量 22），**只**镜像「入口接受的 **Player** 可信请求及其原始提交 Tick」。
- **AI / System 不镜像**：它们在新模拟里由**相同初始输入与 RNG 从 Tick 0 重建**；若额外记录其请求或 Envelope，**只能用于差异诊断，回放时不得再次注入**。
- 比较面至少覆盖：**命令接受/拒绝、命令顺序、AI 决策检查点、最终事实**。
- 镜像点（C1 已给出）：在唯一模拟入口（`BattleSimulation.Step` 之前冻结批次之后）调一次 `RecordFrozenBatch`；Step 之后按「登记 Envelope → 折叠事件 → 对未被拒者 `RecordAccepted`」三步收口。**双记**会让同一条命令同时出现 `Accepted` 与 `ProcessorRejected`（这是驱动器契约，别违反）。
- **Shadow 零写入**：新模拟不得绑定 View、不得修改 Unity 或旧逻辑状态、不得播放反馈或决定场景胜负；推进只在 Bootstrap 的 `Update()`，比较只在同一 Bootstrap 显式排序的只读 `LateUpdate()` 检查点（不变量 22）。
