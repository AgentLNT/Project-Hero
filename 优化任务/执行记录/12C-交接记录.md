`DecisionSnapshot.AdrenalineLedgers` 对每个控制者公开全部单位的可用值、CycleId、ReservedTotal 及预留明细，按 UnitId 排序并冻结集合。`AiDecisionContext.AdrenalineLedgers` 直接读取相同快照。`IViewPreviewPort.AllAdrenaline` 替代 `OwnAdrenaline`，基础界面逐单位显示 Available/Reserved。控制权过滤继续隐藏他方 Editable 普通计划。

## 端口与调用范围

入口为 `BattleSimulation.HudPreviewFor(ControllerId)`；View 从 `IViewPreviewPort.HudPreviews` / `BattlePresentationModel.HudPreviews` 读取。仅在已提交边界获取，不在 Step 内调用。没有控制者的规范快照不能作为 HUD 输入。

| 接口 | 输入/返回 | 可见性与求值依据 |
|---|---|---|
| `WindowSequence` | 当前与后续至少两窗口的 OwnerUnitId、OpenedAtTick、EndTick、IsEstimated | 生产窗口排序和同一 Step；当前为事实，未来统一标预计。战斗结束或无后续排程的测试世界不虚构窗口 |
| `KnownHorizonTick` | 下一非本控制者窗口的打开 Tick；不存在时 null | 同一窗口序列求值 |
| `ReactionOptions`、`HasFeasibleReaction` | 本控制者所有开放机会的每个已发布选项及是否至少一项可行 | `ReactionOpportunitySystem.PreviewStart`、公开账本与同一落点候选求值器；只提供自动暂停依据，未接入 M1 自动暂停策略 |
| `PreviewReaction(ReactionOpportunityId, ActionSpecId, long? startTick)` | 默认起点 SourceImpact；可行性、稳定拒绝码、区间、所需/可用值、冲突计划 | 冲突计划带 State/Origin，HUD 可据此区分 Editable 与不可编辑；他方机会拒绝为 OPPORTUNITY_NOT_OPEN |
| `PreviewDefense(ActionPlanId)` | 已公开或己方可见 Block/Dodge/Guard | 克隆可见计划并运行同一 Step，视界内首触发 Tick/合格来源、抢先标记、Guard 逐 Tick 扣减与剩余、让出 Tick |
| `PreviewDefense(ReactionOpportunityId, ActionSpecId, long? startTick, GridPoint? destination)` | 本控制者拟放置 Block/Dodge | 在隔离世界使用同一反应接受路径，再按上述方式求值；不替用户提交 |
| `PreviewGuard(OrdinaryPlanRequest)` | 本控制者拟放置 Guard | 使用同一排程编辑器及窗口/并发权限，失败返回拒绝码；成功按 Step 求 Guard 额度 |
| `PreviewYield(ActionPlanId)` / `PreviewYield(OrdinaryPlanRequest)` | 已有可见普通计划 / 本控制者拟放置普通计划 | 对每个相关软段反应返回是否实际让出及 Tick；前置接触已经消耗的反应不误报让出 |
| `OpponentCapabilities` | 本控制者每个已公开攻击的每个合法他方目标 | 复用目标收集、ActionSet、反应选项、公开资源/硬占用判定；即使无机会也返回目标及空选项；CanBlock/CanDodge、届时后摇、是否在视界内 |

## 缓存、隔离与结果边界

每个已提交快照/控制者缓存一个服务，首次获取冻结可见输入；各属性和按请求键的查询惰性求值并缓存。旧服务在战斗推进后仍表示原快照，下一提交返回新服务。相同请求复用结果对象。请求键包含起点、落点或完整 OrdinaryPlanRequest，避免将不同候选误用同一结果。

隔离世界只复制公开单位/状态/效果/资源、窗口事实、公开与己方计划及它们的路径/落点/机会。独立 ID 从可见事实推导，不复制权威 RNG、AI 内部状态、未来命令桶或他方 Editable。AI 观察器没有挂到预测世界；预览不写回战斗、不进入权威 AI 决策。移动、接触、额度、终态、启动门禁和窗口开启均运行原有 Logic 求值器，UnityView 只展示结果。

预览以“没有新增输入”为条件；未公开的他方普通计划或新接受的反应、未来命令以及视界外信息允许改变实际结果。视界内公开事实相同且无新增输入时应一致。Block/Dodge/Guard 只展示视界之前的接触；未来窗口为预计。对方能力使用当前公开 Available，不承诺未来尚未发生的奖励到账。后摇标记来自公开攻击区间；未公开干预仍可改变该区间的实际结局。

为直接复用原 Step，在既有 Ledger、状态、移动、Dodge、Buff、机会、窗口、并发类仅增加 `partial` 声明；内部复制接缝集中于新增 `HudPreviewWorld.cs`。这些接缝不提供公共 Restore、不改变原执行路径。Editor 迁移证据加载器切到新的 12C 清单，避免改写旧 12B 证据；此处为收尾所需最小跨目录改动。

## HUD 接续

M1 用窗口序列、已知视界及 HasFeasibleReaction；M2 用公开资源和 OpponentCapabilities；M3 用反应可行性、接触、Guard 额度与让出点。M4 的任意时间游标残影、击退停止格预测和产品布局不由本端口承诺，需要其独立实现。

基础界面已显示全部单位的肾上腺素与英文 `Opponent cannot react` 提示。实际主场景重击在 Tick 361 预告、Tick 441 命中，敌方 Available=0，Block/Dodge 均因 ADRENALINE_INSUFFICIENT 禁用；实际无敌方反应且伤害 20480 Q10，与预告一致，文件重演 100 次。截图见 [资源](12C-main-all-adrenaline.png)、[无法反应预告](12C-main-opponent-cannot-react.png)。
