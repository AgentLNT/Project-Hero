# 主动接近目标的验证方法

本轮为第二项，固定任务 19 的正式内容与防御应对评价，明确谨慎防守在无威胁时主动接敌。`ApproachWhenUnthreatened` 默认关闭，只有显式打开时写入 `public-unthreatened-approach-v1` 哈希组件；旧定义与回放编码保留。

## 决策契约

先运行原来的反应优先和普通效用选择。普通动作没有正收益时，接近目标可替代等待：

1. 控制者有普通提交窗口，处于既有思考节奏，现有候选允许承诺动作。
2. 没有公开、未结算的敌方攻击，也没有仍公开可用的反应机会。这里保守地按公开攻击判断，不声称能精确证明所有来袭攻击是否一定命中。
3. 存在完整合法攻击候选，且所有未拒绝的攻击结果已覆盖；没有任何攻击在无追加应对条件下产生正的敌方生命损失差额。已有有效攻击时，压力/耗资价值仍交回原评分，不继续追近。
4. 移动须通过原内核预演，结果完整、没有计划终止原因，缩短既有距离指标，且不增加己方承伤、不减少敌方伤害。
5. 按距离进展/承诺 Tick 比较，使用整数交叉相乘；同等效率取更短承诺，再按原效用和稳定键决胜。原效用仍显示原值，即使是负值；选择原因明确标为接近目标。

距离指标沿用原评价中受控单位到最近敌方单位的整数曼哈顿距离之和。候选仍为原有局部目的格及共享路径求解，不新增全图攻击站位搜索；局部候选无安全进展时允许等待，不把该情况宣称为证明目标不可达。没有持久目标、额外时钟或行为树记忆，所有未来影响仍由既有命令、任务与计划记录承担。

## 测试与正式内容对照

专项测试覆盖双镜像真实移动及原评分保留、近距攻击保持、安全/覆盖/拒绝/终止边界、缺窗口/缺攻击能力、公开反应机会阻止目标覆盖、等效率短承诺及稳定平局。排序端口夹具从真实预演提取摘要后构造等效率对照；人工摘要仅检验选择契约，不冒充真实移动路径。

正式矩阵为谨慎防守 × 原始远距/近距 × 两种镜像，4 场，每场最多 240 Tick。新版为完整自主 AI，命令只经注册入口；记录磁盘回放和逐候选分数/选择原因。旧版基线从任务 19 封存回放重新运行前 240 Tick，按同终点比较命令、移动、攻击、距离和生命损失。时间截断不计胜负或平局。

`ApproachGoalTools.Audit` 在另一个 Unity 进程中核对输入/源码/内容指纹，重新生成新版 AI 请求，逐 Tick 比较事件与完整快照哈希，并逐行重建候选日志。另完整重演任务 19 三种风格 × 两布局 × 两镜像共 12 场，以验证关闭新开关时的兼容性；重新生成旧版同终点汇总。

正式场景测试显式启用谨慎风格和接近开关，通过唯一生产时钟运行并重演回放；其它已有生产/Shadow/玩家入口检查继续回归。正式场景默认控制配置不切换，正式资产、数值、资源规则和原评分权重不改。全量 PlayMode、正式性能以及完整多步施压价值仍为其它验证范围。

## 产物与恢复

本轮起点包括任务 19 尚未提交的工作，`before-task.zip/json` 保存当前工作区原字节，不能用 HEAD 覆盖。保护清单包含正式内容、依赖及 `AiUtilityProfile.cs`；任务 19 的封存目录逐文件哈希校验。

测试生成的旧证据、隐藏场景、项目设置及指定测试资产先封存再恢复。`evidence.py analyze` 核算结果，`restore` 恢复生成副作用，`seal` 校验源码/内容并封存。最初失败回归与固定时长夹具失败日志保留，不计最终通过项。

使用项目既有 Unity CLI beta.13 和 Editor 6000.6.2f1。命令输出均显式放入本专题目录：

```powershell
unity test . --mode EditMode --output '优化任务/执行记录/主动接近目标-2026-11-11/full-editmode.xml' --timeout 1200 --format json -- -nographics -logFile '优化任务/执行记录/主动接近目标-2026-11-11/full-editmode.log'
unity run . --timeout 1200 --format json -- -nographics -executeMethod ProjectHero.Editor.ApproachGoalTools.Run -logFile '优化任务/执行记录/主动接近目标-2026-11-11/run.log'
unity run . --timeout 1800 --format json -- -nographics -executeMethod ProjectHero.Editor.ApproachGoalTools.Audit -logFile '优化任务/执行记录/主动接近目标-2026-11-11/audit.log'
```
