## 状态流与终止原因

三种规格只保留 `DurationTicks`，无防御前摇和后摇，不按速度缩放；默认 Guard / Block / Dodge 为 60 / 60 / 30 Tick。`EndTick = StartTick + DurationTicks`，末端不生效。

| 动作或路径 | 状态与结果 | 原因编号 | 肾上腺素与空间 |
|---|---|---|---|
| Guard 起点至末端 | 普通计划启动即 Guarding；自然走完 Completed | 既有自然完成 | 无反应预留 |
| Guard 额度用尽 | 本 Tick 伤害提交后终止并回 Idle | GuardQuotaExhausted = 18 | 不再抵抗后续 Tick |
| Block 首次合格接触 | 起点即 Blocking；本 Tick 全部合格载荷被抵抗，然后终止 | ReactionTriggered = 15 | 实际触发时消费一次 |
| Dodge 首次旧格合格接触、换位成功 | 起点即 Dodging；空间事务成功后按旧格/新格表结算并终止 | ReactionTriggered = 15 | 消费一次，成功奖励仍保留 |
| Dodge 落点复核失败 | 无换位、无成功奖励，仍消费并终止 | ReactionTriggered = 15 | 不退款；移动族保持原状 |
| Block/Dodge 末端仍未触发 | 到 EndTick 终止 | ReactionExpired = 16 | 不退款，释放落点 |
| 普通计划到达反应软段启动门禁 | 先终止未触发反应，再启动普通计划 | ReactionYieldedLane = 17 | 不退款，释放落点 |
| 来源在 SourceImpactTick 之前或当 Tick 取消，反应尚未触发 | 现有来源取消路径终止反应 | SourceThreatCancelled，既有编号 | 仅同周期退款，释放落点 |
| 来源未命中，随后在 SourceImpactTick 之后自然完成 | 反应保留，仍可由其他接触触发 | 不产生来源取消终止 | 保持预留至触发、让出或过期 |

新增原因接在 12A 的 `DelayedBeyondSourceWindow = 14` 后面，不复用任何既有稳定值。机会的 `Triggered` 状态与计划的 `ReactionTriggeredAtTick` 记录实际生效 Tick。`SourceImpactTick` 只表示来源边界，不再作为生效条件。

## Step 接入与提交边界

| 既有阶段 | 本轮内部步骤 |
|---|---|
| 0 | 到期未触发反应以 16 终止；Guard 到期自然完成 |
| 7 | 控制中断后先推进到起点的反应，再处理普通启动门禁；软段反应先以 17 让出；Dodge 可容忍的未来 Move 使用 R1 同一求值器延期 |
| 8 | 冻结本 Tick 的 Intent，防御计划在完整新区间参与物化 |
| 9 | 以冻结 Intent 与换位前空间建立纯旧格接触图，探测 Dodge；按实际触发集合稳定复核并原子换位，然后确认触发与消费，包括复核失败路径 |
| 10 | 构建旧格/新格正式冲突图后、Block 求解前，纯探测 Block 接触；确认触发后求解全部合格载荷；Guard 按实际比例生成额度扣减事实 |
| 11 | 同一提交方法内提交 Guard 额度及 `GuardQuotaConsumedEvent` 与目标聚合伤害；同计划本 Tick 最多一次额度扣减 |
| 14 | 本 Tick 生效反应与耗尽 Guard 先进入统一终态，再提交控制/拦截、聚合奖励、自然完成；不增加 Step 阶段 |

`DefenseContactDetector` 无状态写接口，只读本 Tick 的冻结接触。生效判断不依赖动画、上一 Tick 结果或单位状态。Block/Dodge 的首个接触可以来自任意满足标签、阵营和空间条件的攻击。Dodge 稳定次序为同一实际 Tick 内的 `(Destination.X, Destination.Y, CommandSequence, OpportunityId)`。

接受 Dodge 时预留整个所选 `[StartTick, EndTick)` 的落点生命周期；提交只选择本 Tick 真实触发的预留。纯诊断请求若省略末端，保留来源边界作为默认诊断区间。移动族只在真实换位成功后失效，失败不会改变其起点、路径、修订号或终态。

## Guard 额度与整数精度

初始额度 1024。每通道和动量的实际比例分别为 `min(配置比例, 剩余额度)`；仅对真正合格且非零的载荷参与扣减，扣减值取这些实际比例的最大值，同 Tick 只扣一次。额度始终非负，最后一次接触先完成抵抗与伤害，随后终止 Guard。

Guard 的抵抗量向下取整：`抵抗量 = floor(被动后载荷 × 实际比例 / 1024)`，剩余量为载荷减抵抗量。普通 RoundHalfUp 会使三次 2 单位载荷、比例 341 各抵抗 1，累计 3 超过一次 Block 的 2；该边界已由回归测试固定。其他动作的舍入保持原规则。规则哈希新增 `rules.guard_initial_quota_q10` 与 `rules.guard_resistance_rounding=FloorResistedQ10`。

属性测试固定种子生成 2000 个序列，每序列 64 Tick、每 Tick 1–4 个接触；包含两个独立伤害通道、0–1023 的 Guard 比例、0–1024 被动比例、整数 Q10 伤害、0–10000 动量、混合 Guardable 标签与可/不可格挡动量。对真实 `TargetAggregator` 输出逐通道及动量分别累计，断言不超过该序列最大单 Tick 的被动后载荷。另有微量载荷与同通道混合标签反例。多 Guard / 多反应排列测试比较真实 Step 的逐 Tick 事件、哈希、额度与预留。

Builder / Validator 拒绝任一 Guard 比例 ≥ 1024、Guardable 但不 Blockable 的伤害分量。Guard 动量只抵抗带 Blockable 攻击标签的动量；同一通道的未标记分量不会继承其他合格分量的动作抵抗。

## 起点、截止与占用矩阵

命令新增可空 `StartTick`，缺省取 `SourceImpactTick`。在处理 Tick T 必须满足 `T+1 ≤ StartTick ≤ SourceImpactTick` 且 `StartTick + DurationTicks > SourceImpactTick`，越界统一为 `REACTION_START_OUT_OF_RANGE`。范围和占用在分配计划、预留空间、预留资源之前验证。

选项截止为 `SourceImpactTick − CommandIngressLeadTicks`；公开条件仍为截止 ≥ TelegraphTick + ingress lead。AI 和输入预览按命令实际目标 Tick 判断截止，不把展示 Tick 当处理 Tick。

硬段是闭区间 `[StartTick, SourceImpactTick]`，内部统一使用 `[StartTick, SourceImpactTick + 1)`；后面到 EndTick 的区间是软段。

| 新计划 | 已有普通计划的占用 | 已有反应硬段 | 已有反应软段 |
|---|---|---|---|
| 普通计划 | 既有串行及编辑 ripple 规则 | 请求起点的硬交集拒绝 | 可预览并提交；到启动门禁时未触发反应先让出 |
| Block | 新硬段相交则拒绝 | 硬段相交则拒绝 | 硬段不相交允许，仍检查其他计划 |
| Dodge | 同 Block；保留自身将使之失效的 Editable 未来 Move 容忍 | 硬段相交则拒绝 | 同 Block |

`ActorLane.HardIntervalsConflict` 为编辑和提交共享判据；只缩短反应硬占用，不缩短防御生效区间。Dodge 容忍的 Move 到门禁时若仍受硬段阻塞，通过 R1 求值器移到硬段末端，继续执行来源窗口校验；软段门禁先清反应再启动，阶段边界上不保留普通计划和反应同时 Running。

两个来源硬段互不相交的反应可以软段重叠；各自首次合格接触均消费，但相同攻击目标载荷只聚合一次，避免软段重叠导致重复伤害。非法的其他重复载荷仍由原有不变量拒绝。

## AI 与最小表现

AI 首版固定显式选择 `StartTick = SourceImpactTick`，采用等待来源命中点的策略。更早的已知接触位于起点之前，因此不会消耗该反应；同 Tick 接触由 Block 一起覆盖。AI 检查自身现有计划的硬段、可容忍的未来 Dodge Move 及命令目标 Tick 的截止，避免提出必然因自身硬占用或入口延迟被拒绝的候选。

现有 Canvas 的反应按钮显示逐选项截止与默认起点。`BattlePresentationModel.ConfirmReaction`、Dodge 预览及 View 输入端口支持可空所选起点，实际 Logic 预览使用完整所选区间。无肾上腺素公开策略变更，完整反应卡与其他 HUD 体验仍属于后续包。

## Shadow 分类、删除与扫描

原 62 项分类保留，追加 11 项成为 73 项：6 项 `RemovedRepresentation` 为 activeStart、activeEnd、reactionWindup、activeTicks、旧事件与旧 Resolution 属性；5 项 `NewRule` 为 duration、quota、actual trigger、source boundary、deadline。每项引用已通过的实际原生测试名称，并绑定源码和 EditMode/分类前 PlayMode XML 的 SHA256。

隐藏场景加载当前证据契约后，以真实公开、已确认的未来攻击检查共同字段、逐条分类和证据指纹；漏项、重复、错类别、过期源码或无执行证明会失败。Legacy 无法表达的新规则由分类与规则测试证明，不宣称整个旧/新玩法等价。旧的暂不可比披露及新实现独立重建的比较范围仍保留。

新生产路径旧术语仅剩 `ShadowCasePolicy.cs` 的两行 RemovedRepresentation 名称登记；测试中的 `NoCounterWindowEventIsEverEmitted` 是必需负断言。Legacy、历史任务文档、归档日志、迁移映射和验证脚手架的所有其余匹配在扫描 CSV 逐行解释。扫描覆盖忽略及未跟踪文本，排除 Unity 生成目录、Git 数据及第三方缓存，避免把缓存副本当生产字段；`EncounterWindow` 表示遭遇窗口，作为与反击窗口无关的子串误报排除。

反击窗口事件、Resolution 和属性已经删除，无新奖励、反击 buff 或复用编号。只验证旧时序的测试改为验证新区间；混合测试保留无关断言。`DodgeWithoutRelocationDoesNotInvalidateMoves` 保留失败空间事务的原断言，生产失败的消费与终止另由新测试证明。时间线拖拽测试把 Move 与 60 Tick Guard 衔接，仍验证 ripple、一次确认、删除不左压及修订重基。

## 12C / HUD 接手位置

`ReactionOpportunitySystem.PreviewStart` 返回纯只读 `ReactionStartPreview`：所选 Start、End、SourceImpact、HardEnd、已知普通计划的 `KnownYieldTick` 和拒绝码。它复用 Logic 的时序与占用规则，不预留资源或落点，不保证未来能命中；View 的 Dodge 预览另调用只读空间校验。`ActionPlanSnapshot.DefenseQuotaRemainingQ10` 提供 Guard 剩余额度，`ReactionTriggeredAtTick` 提供实际生效点。

12C 可在这一 Logic 入口接上公开资源与预计生效接触；预计接触必须由公开计划和 Logic 空间投影推导，不能让 HUD 自行从动画或 UnitState 猜测。预计让出点已有 Logic 输出，仍是已知计划投影，不是未来输入承诺。完整 HUD M3 的展示和交互须另行验收，继续使用 12A 的唯一 `IScheduleWindowAuthority`。
