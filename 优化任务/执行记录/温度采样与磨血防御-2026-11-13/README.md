# 任务22：温度采样与磨血防御策略

2026-11-13。**首轮实施与验证完成，方案22的行为验收未通过，不采用为正式配置。** 可选机制、正确性验证、315场对照及全部独立审计已完成；持续施压目标仍未完成。生产资产、战斗数值、原效用权重及默认入口不变，`Sampling=null`继续使用旧策略。

新机制按预期实现了负分采样、可防御目标的负伤害排序和随血线降低而提高的防御价值，但完整对局出现大量预演零伤害攻击，未形成有效的小招持续施压。不能以测试和确定性通过代替行为验收。

## 实施与验证

- `AiSamplingSettings`：不可变参数、分组/评分版本及配置哈希。`AiSoftmax`：固定decimal指数、带种子随机数、按动作分组的温度/top-p采样；相同评价的落点复制不增加动作组总概率。
- `AiPressurePolicy`：显式Wait、按敌对目标真实防御预演计算符号、Guard部分减伤、生命零点截断、有限血量曲线、致死存活收益及余额/个人清零时机的资源估值。
- `AiSamplingMemory`：无准入事实变化时保持不应对选择，避免逐Tick重抽；记忆进入控制者规范快照和哈希。原行为树继续管理真实提交与计划终态。
- 全量EditMode **1206/1206**；生产/Shadow定向PlayMode **21/21**。不是全量PlayMode或正式性能验收。
- **114场**机制实验在Unity/Mono与.NET逐项一致：完整逐Tick快照与事件、评分、概率、抽中项和记忆；每场均完成原生回放验证。另以当前源码核对任务21的4场/7200 Tick原生参照，通过。
- 正式内容对局 **315场 / 1088366 Tick**：A/B/C/D各54场、D第二种子54场、五档分批扫描各9场，全部通过另一进程逐Tick快照/事件、候选/决策和指标重建。后两类与主矩阵独立报告；探索性的`pilot/`四场不计入315场及正式结论。每批`disk-audit.txt`保留实际审计数量。

A共157572 Tick，有效生命损失11100、过量276点；54场权威回放与任务21封存文件逐字节相同，主要指标相同。B共193074 Tick，过量30点；C/D各193904 Tick，过量0。B/C/D全部零实际命令拒绝、零未覆盖评价，但攻击命中效率与结束率明显退化。

C/D抽中的1429个攻击中，1281个（约89.6%）在无防御预演里就没有有效伤害。快斩启动增加到194次，真正造成正伤害仅3次，不能称为小招磨血改善。D第二种子54场仅2场结束，抽中的1440个攻击中1297个零伤害，问题延续。

独立合法反应机会：B为112个，其中110个选择并实际接受反应、109个实际触发、68个反应计划取得成功防御；C/D各12个，12个选择并接受、5个实际触发、2个成功。实际触发率分别为109/112与5/12，不能将抽中或创建计划当作防御生效；触发后也可能未避免接触。逐项见[实际反应结果](defense-outcomes.json)。C/D的总体对局指标一致，这批对局不足以分离血线曲线的作用，也不能把全程资源不足/轨道不合法的候选算作选择挨打。具体血线效果由下述控制机制场景验证。

Python另外逐事件核对Available连续性、预留创建/消费/退款/作废与跨周期删除，并验证每单位“实际入账＝消费＋清零＋终局清除＋作废＋截断时余额及预留”的守恒式。D除消费7外，周期清零1194、终局清除9、预留作废6、截断时保留128，合计1344，等于实际入账；不能将截断时余额当作已消费或已损失。

## 可复核反例与血线效果

见[failure-example.json](failure-example.json)。D双谨慎近距非镜像，Tick240，英雄生命180、可用资源4。旋风斩无防御预演伤害0，分数-2112并被抽中；同一时刻可造成40/25/20点有效伤害的重砸、突刺、横扫，因为目标有合法反应，分数为-42901/-26657/-21753。零命中的攻击被排在有效攻击之前。这证明“只改为负D0，再提高探索”不足以保证有效施压。

真实受伤形成的血线探针保留了同资源、同威胁条件。持续进攻偏好、最大生命42、可用资源1点、相同4点威胁时：

## 参数与采用结论

初版实验参数为：尺度16384、温度1、top-p=1、低血量曲线增益4、每点资源基础估值8192、存活价值262144。它们进入配置哈希，**仅作为可重演对照参数保留，不作为正式选定值**。

额外扫描每档9场，只比较三种相同偏好在三种布局的非镜像样本。贪心温度0结束6场但仍无资源消费；温度0.25、2.0及固定温度1的top-p 0.95/0.9均为0/9自然结束，未消除零伤害攻击偏好。相同数值温度在三种不同幅度的原效用权重下也不代表相同探索强度，尚未得到可采用的共用标度。

**未完成：有效小招持续施压、由磨血推动完整对局防御循环、可采用的初版权重/尺度/温度/截断。** 下一轮须先对照“真实可命中攻击与零伤害攻击的机会价值”和采样中的接近/等待收益，再单独调整相关评分与资源参数。不能靠压低Wait常数或用top-p把问题候选截掉后宣布完成。资源费用、入账、清零及正式战斗数值仍可按证据做独立对照；本轮保持原值是为了隔离输入，不是认定其已平衡或禁止调整。
