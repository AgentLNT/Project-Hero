# 阶段三：可解释规则 AI（2026-11-03）

范围：[实施方案第 7 节](../../方案/战斗数值与AI实施验证方案-v0.1-2026-10-28.md)、[任务 14](../../14-可解释规则AI.md)。本轮交付三种可选策略、缺失的候选能力及确定性证据；生产仍默认旧确定性策略，正式数值未切换。

## 实现

`ControllerBinding.AiPolicy` 显式选择 `Legacy / SustainedOffense / SeekInterrupt / CautiousDefense`。非旧策略的种类及 `tactical-public-kernel-v1` 进入定义哈希；旧策略跳过新增编码，旧哈希锚点和 ReplayFormat 7 延续。注册同时拒绝未知策略及给 Player 绑定非旧 AI 策略。

候选构建与评分分别位于 `AiTacticalCandidateBuilder` 和 `AiTacticalPolicy`：

- 攻击按可见目标瞄准；在原排程预览解析前摇后，可为最近两个公开敌方命中时刻生成延迟对齐候选。
- Guard 作为普通动作生成。Move 主动生成规范 12 向、1/2 步距共 24 个目的地，不再只重排已有 Move；路径、边界、占位和时长由原排程/路径求解器判断。
- Block/Dodge 使用公布机会与落点，逐候选走真实资源、时序和轨道检查。反应每 Tick 检查并优先于普通动作；合法反应的最高收益不高于等待时，本 Tick 等待。无合法反应后才进入普通层，不与普通动作混合竞价。
- 普通动作每 6 Tick 思考一次；已有未完成轨道承诺时等待，避免不断追加预测计划。所有入选请求仍经注册入口于下一 Tick 提交，无主动关窗命令。

预览复用 HUD 的隔离世界复制接缝，删除对手未公开草稿及路径，在阶段 18 显式冻结当前决策边界，再运行同一 `BattleSimulation.Step`。AI 只能取得只读结果，不取得模拟写入面；预测不改变真实世界、序号或 RNG。实际生命变化、公开攻击在命中前的终止、拼刀与终点位置来自原内核，AI 不另算伤害、动量、控制或移动时间。

## 评分及限制

预测固定为当前 Tick 后 120 Tick，假设没有后续新命令，仍执行窗口切换、资源重置及已公开动作。它是条件预测，不代表未知对手后续决策。策略没有额外可变记忆；决策计数、下次思考 Tick 及派生 RNG 仍由原运行态快照记录。候选以包含动作、目标、朝向、目的地、机会及对齐时刻的完整稳定键排序，同分保留稳定键较小者。

以等待预览为基准，`D` 为额外敌方生命损失，`I` 为额外友方生命损失，单位均为 Q10；`P` 为最终最近敌方距离的改善，`C` 为新增提前取消数，`K` 为新增拼刀数：

| 策略 | 收益分 |
|---|---|
| 持续进攻 | `8D - 2I + 256P + 1024C + 256K` |
| 寻找打断 | `2D - 3I + 128P + 65536C + 24576K` |
| 谨慎防守 | `D - 12I + 64P + 2048C` |

统一扣除承诺剩余时长×8、反应资源点数×32，以及确有额外伤害时的首次伤害等待 Tick。v0.5 资源原始整数先按 `24576 = 1 点` 换算，避免与 Q10 生命混用。等待分数为 0；没有正收益候选时允许等待。权重是首版策略偏好，不是平衡指标。移动目前仅覆盖 24 个局部目的地，尚无多步战术搜索、对手建模或正式性能验收。

## 代表结果

同一公开重击在 Tick 100 命中，三种策略在 Tick 60 的首选为：

| 策略 | 实际首选 | 核心理由 |
|---|---|---|
| 持续进攻 | 快攻，61 开始、91 命中 | 预览增加 4096 Q10 敌方生命损失 |
| 寻找打断 | 钝击探针，70 开始、100 拼刀 | 原内核确认发生拼刀，降低预期来伤 |
| 谨慎防守 | Guard，61～121 | 原内核确认降低 3072 Q10 来伤 |

另有低稳定度探针验证提前控制取消：寻找打断选择钝击探针，真实敌方攻击在 Tick 100 前终止。远距场景选择主动 Move；仅 Guard 场景真实生成 Guard 计划；足额资源场景经真实受击获得资源后选择 Block；不足时记下 `ADRENALINE_INSUFFICIENT` 并等待。Dodge 的公布落点参与合法性及收益比较，本组足额场景最终选择 Block。
