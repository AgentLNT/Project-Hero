## 新增与归档约定

- 新优化方案放入 `方案/`，在本导航中补充入口；新增任务包沿用编号方式并更新依赖关系。
- 交接、验证脚本和验收产物放入 `执行记录/`，使用任务编号或日期命名；新增一组操作截图或日志时可按专题建子目录，并同步记录导航。
- 测试命令和导出工具应显式指定 `优化任务/执行记录/` 下的输出路径，避免再次写入仓库根目录。
- 既有任务包和执行证据路径保持稳定；原始结果、日志、回放与指纹不因目录整理而重写。历史文字中的旧路径按[2026-10-26 迁移记录](../设计文档/维护/优化任务目录整理记录-2026-10-26.md)追溯。
