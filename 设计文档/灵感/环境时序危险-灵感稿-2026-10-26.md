# 环境时序危险（灵感稿）

日期：2026-10-26。状态：用户认可的方向，作为正式内容搁置，近期不加入；规则尚未冻结，也不作为当前功能承诺。现行规则把“可破坏环境、地形杀”列在首版范围之外（见[游戏设计文档](../游戏设计文档.md#对照)末尾的对照表），目前也没有环境危险的代码。

## 1. 来源与动机

用户的灵感来自《博德之门 3》：常规探索中开启回合制模式时，会多出一个环境回合。

本作可以更进一步：环境不必占一个回合，而是和所有单位共用同一条连续时间。来回摆动的机关、间歇喷涌的岩浆，可以在一个单位的窗口内变化好几次。这是其他回合制游戏难以复制的特质。它也提供了一种时机压力，不依赖 NPC AI 是否聪明：环境的时刻表是确定且公开的，玩家只需要读懂它（参见[分层方案](../界面/HUD常规界面与介入界面分层方案-讨论稿-2026-10-17.md) §9）。

## 2. 要避免的退化

环境在单位窗口内外的作用完全不同：

- **窗口内**是时机题：等摆锤荡过去再穿过，趁岩浆喷发的间隙通过。
- **窗口外**，单位只能格挡或闪避，位置基本冻结。动态危险对一个不动的单位只有“打得到”和“打不到”两种结果，于是退化成一面静态的墙。

若不处理，就会固化成一条免费的常识：“窗口结束时别站在会变化的格子里”。目标不是消灭这条规则，而是让遵守它有代价、违反它有回报，使它始终是一个决策。

## 3. 主线：环境是公开时刻表上的攻击

每次喷发或扫过，都按“预警 → 生效 Tick → 冷却”建模，与攻击的“前摇 → 命中 → 后摇”同构。站在危险格里度过别人的窗口，结果不是必死，而是三选一：花肾上腺素格挡或闪避、硬吃伤害，或者（仅主角）付费取得并发授权，在别人的窗口里挪开。

| 想要的效果 | 复用的现有机制 | 需要新增或明确 |
|---|---|---|
| 喷发、扫过造成伤害与击退 | 攻击的伤害分量与动量包、ImpactProfile、剩余命中阶段 | 环境来源（不是单位、没有阵营）与危险定义 |
| 站在危险格里可以花资源挡 | 反应机会、Block/Dodge、肾上腺素 | 机会何时创建，见 §6 第 1 项 |
| 穿过时被扫到、或刚好离开 | 冲突求解第 4、5 阶段：拦截与逃脱 | 无 |
| 被推进危险格 | 同时强制位移；M4 的击退停止格预测 | 无 |
| 摆锤的摆臂暂时挡路 | 限时空间阻塞（已用于计划延期） | 环境作为阻塞来源 |
| 主角在他方窗口挪开 | 并发授权 | 无 |
| 不能与环境拼刀 | — | 环境接触不进入 Clash 阶段 |

首版建议只做**脉冲型**危险：每个周期只在一个 Tick 生效，与攻击相同。持续型地表（例如岩浆池每 Tick 灼烧）与“格挡只生效一次”的规则不兼容，留到以后作为状态效果处理。

时刻表由 Encounter 定义：周期、相位、预警时长、生效区域与载荷，全部是整数 Tick，不使用随机数，保证可重演、可预览。

## 4. 配套：让站位既是武器也是代价

- **位置是武器。** 把敌人推进岩浆，并让落点时刻正好在喷发之前，这就是“地形杀 + 时机”。敌方 AI 会遵守“别站在危险格”，这反而让敌人的站位可以预测、可以利用。
- **危险格值得站**（关卡设计手段）：
  - 危险格正好是要道、高地、掩体或目标，例如拉杆就在摆锤的路径上；
  - 机关周期与窗口轮转不对齐，每一轮的安全格都不同；
  - 安全格少到需要抢。

## 5. 界面

### 介入时间轴：环境单独成行

示意图：[环境行示意](环境时序危险-示意图-2026-10-26/README.md)。因为本内容已搁置，图放在灵感目录，不放进界面示意图目录。

- 在窗口条与单位轨道之间固定一行“环境”，不参与阵营分组排序，也不占“一主选＋四紧凑”的名额。按 M2 的尺寸，表头、环境行、一主选＋四紧凑合计约 `62 + 32 + 2 + 88 + 4×32 + 4×2 = 320` 个 Canvas 单位，比现有布局多 34。
- 默认只显示与已选单位相关的危险：作用区域覆盖其当前位置或计划位置的，再加上镜头内的危险。多个危险合在一行，分段标名；超出时显示“+N”，可以展开成每个危险一行。
- 每次生效画成“预警 → ◆ → 冷却”，从环境行向受影响单位的轨道连接触线，与跨轨道攻击的表达一致。环境使用独立的色相和图标，不用敌方的红色，因为它对所有阵营都生效。
- **已知视界**：周期型危险是确定的，所以环境行可以越过视界线照常绘制，不画“？”。但视界外各单位的位置未知，接触点画成空心。
- 触发型机关（压力板、拉杆）的时刻表取决于单位行动，只能在视界内预测，用虚线表示“条件触发”。首版不做。

### 常规层

- 只读位置条上，环境受击用与敌方 ▲ 不同的符号标出。条尾增加“空闲到下一个自身窗口”这一段，按最后的站位标出期间的环境生效，例如“空闲 6.8—9.0 s · 7.5 s 岩浆喷发”。回合末站在哪里，于是成为按当局计算的选择。
- 战场上给危险格加倒计时，例如“1.2 s 后喷发”。移动路径预览要标出经过时刻是否与生效重合，例如“经过此格 1.2—1.4 s，摆锤 1.3 s 扫过 → 被拦截”。
- 反应卡把环境威胁和敌方攻击放在一起排序，来源写作“环境 · 岩浆口 A”。

## 6. 待决问题

1. **环境威胁的反应机会何时创建。** 现行规则是攻击锁定、启动并公开后才创建机会。
   - (a) 预警开始时创建，与攻击一致。代价是别人的窗口里会频繁触发威胁暂停，而且玩家在自己的窗口内无法预先安排。
   - (b) 生效时刻进入前瞻范围（例如截至该单位下一个自身窗口）时就创建，玩家可以在自己的窗口里一并排好“移动 + 格挡 7.5 s 的喷发”。这需要为环境开一个例外：固定时刻表视为已锁定并公开；受威胁的判断改用预测位置，位置变化时机会随之失效或重建。

   **用户已选 (b)（2026-10-26）。** 它把环境的确定性变成规划能力，也避免暂停刷屏。由此需要明确的细节：
   - 前瞻范围：暂定截至受威胁单位的下一个自身窗口打开。
   - 预测位置：按该单位已排计划推算生效 Tick 时的站位；计划变化后，机会随之失效或重建。已接受的反应若因机会失效而解绑，是否退款，按现行“主动取消不退款”处理还是另定，待议。
   - 视界外的变数：敌方在视界外的动作可能改变站位。机会仍按预测创建，界面把接触点画成空心并提示风险；被推离时格挡落空，现行规则不退款。
2. **威胁自动暂停是否包括环境。** 随 (b)，建议环境威胁默认不自动暂停，因为已经可以预先安排；只在机会因站位变化新出现、且截止前没有自身窗口时才暂停。待确认。
3. **阵营。** 默认影响所有单位。“我方可启动、只伤敌方”的机关留待以后。
4. **肾上腺素。** 承受环境伤害是否产生收益？要防止故意站进弱危险格刷肾上腺素。
5. **周期与窗口的关系。**
   - 固定周期：与窗口错开，每一轮的安全格都不同。
   - 窗口交接时触发：类似《博德之门 3》的环境回合，但会重现“回合末别站”的规则。

   倾向以固定周期为主，交接触发只作为特定关卡的节奏手段。
6. **AI。** 敌方 AI 要会躲避危险，也要会把玩家推进危险格。因为时刻表确定，这比读玩家的计划容易，可以在[基础战斗与 AI 测试方案](../战斗测试/基础战斗与AI测试方案-v0.1-2026-10-21.md)中作为单独场景测试。

## 7. 进入实施前需要的规则工作

- 在冲突求解中增加不属于任何单位、不属于任何阵营的环境来源，并定义它与各阶段的关系：可被 Block/Dodge，适用拦截与逃脱，不参与 Clash。
- 定义危险时刻表（HazardSpec），纳入配置哈希，并在回放中可重演。
- 为环境反应机会写明 (b) 的例外：固定时刻表视为已锁定并公开；按预测位置判断受威胁；定义前瞻范围，以及机会失效与重建的条件。
- 明确 §6 第 2 项，同步主方案与游戏设计文档后，再更新 HUD 方案。
