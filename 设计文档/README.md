## 维护规则

主方案是精确规则依据，游戏设计文档是阅读摘要，HUD 文档是体验契约，任务包是施工要求，执行记录是当轮证据。代码与设计不一致时分别记录事实和差距，不能把计划写成已实现，也不能用过期证据宣称新修改已验收。

新增文档放入相应分类，更新本导航。新增玩法先明确范围、同步主方案及设计，再更新版本、配置和验证。历史和原始证据不批量改写；其中旧路径按[迁移映射](维护/项目结构与整理记录-2026-10-13.md)追溯。移出 Assets 的 Markdown `.meta` 随原稿归档，不再作为 Unity 导入资源。
