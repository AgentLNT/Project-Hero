技能系统方向（2026-10-21）：当前不计划引入复杂技能，魔法尚未实现，优先改善现有动作的配置、校验与制作流程。[Flexi 试接入方案](技能系统/Flexi试接入与技能制作方案-v0.1-2026-10-21.md)已延期，[GAS 框架调研](技能系统/GAS框架选型调研-2026-10-21.md)保留备查；尚未安装或接入。后续根据真实的效果组合与技能联动需求重新评估，不把加入魔法视为必须采用 GAS 的条件。

战斗测试规划（2026-10-21）：[基础战斗与 AI 测试方案 v0.1](战斗测试/基础战斗与AI测试方案-v0.1-2026-10-21.md)用三个攻击样本、两种敌人行为和单挑/小队遭遇验证时间、站位与反应取舍。经数值复核，原 B0 临时参数暂缓采用，先统一生命、伤害与个人周期反应收支尺度；数值方向为参考 D&D 的小数值可读性并保留足够颗粒度，小额收益累计与显示/内部精度建议见 §0.1。固定局面对照和试玩结构保留。当前为方案，尚未制作配置、修改 AI 或执行试玩。

当前属性设计基线（2026-10-23）：[人物属性与战斗数值完整方案 v0.5](战斗测试/人物属性与战斗数值完整方案-v0.5-2026-10-23.md)汇总力量/敏捷/体魄、三种固定伤害与动量配方、同源强度成长、普通防具增加生命、独立稳定度、速度及肾上腺素规则；含成长/装备门槛、同预算构筑、迁移差异和验证顺序。设计方向已确认，具体系数仍待测试，尚未接入 Unity。与下列旧提案冲突时，以 v0.5 作为后续设计基线，不将其视为当前运行时规则。

历史数值候选（2026-10-21）：[战斗数值模型 v0.2](战斗测试/战斗数值模型-v0.2-2026-10-21.md)提出 24 生命与快斩/重砸/横扫 6/3/8 次有效命中的共同标尺，计算属性成长门槛、动量残余伤害和肾上腺素反馈；附可重跑计算脚本、结果与“伤害增加反而多出手”的离散反例。仅完成数学及简化窗口试算，尚未采用或接入 Unity；旧参数结果不覆盖 v0.5。

动作价值补充（2026-10-22）：[伤害与动量价值分配 v0.3](战斗测试/伤害与动量价值分配-v0.3-2026-10-22.md)将控制、打断、位移与拼刀纳入动作预算，提出用同动作对照测量动量升级价值；保留重砸 6/7/8 伤害分支，避免将裸 DPS 对齐等同于完整平衡。尚未采用或执行 Unity 对照。

## 维护规则

主方案是精确规则依据，游戏设计文档是阅读摘要，HUD 文档是体验契约，任务包是施工要求，执行记录是当轮证据。代码与设计不一致时分别记录事实和差距，不能把计划写成已实现，也不能用过期证据宣称新修改已验收。

新增文档放入相应分类，更新本导航。新增玩法先明确范围、同步主方案及设计，再更新版本、配置和验证。历史和原始证据不批量改写；其中旧路径按[2026-10-13 迁移映射](维护/项目结构与整理记录-2026-10-13.md)及[2026-10-26 优化任务整理记录](维护/优化任务目录整理记录-2026-10-26.md)追溯。优化方案统一放入 `优化任务/方案/`，任务包与执行证据查[优化任务导航](../优化任务/README.md)。移出 Assets 的 Markdown `.meta` 随原稿归档，不再作为 Unity 导入资源。
