# 体积与技能范围编辑器

Unity 菜单：**ProjectHero → 配置工具 → 体积与技能范围编辑器**。
也可以双击 Project 中的 `UnitVolume` 或 `AttackPattern` 资产打开。

## 制作配置

1. 选择“单位体积”或“技能影响范围”，填写配置 ID。现有资产可以拖入“现有资产”，或在 Project 中选中后点击载入。
   制作技能范围时，在“适配单位体积”中选择对应的 `UnitVolume`。单位体积以蓝色显示，技能范围以橙色显示；重叠格仍有蓝色描边。体积与范围共用锚点，并随朝向同步切换。体积仅为只读参照，涂选、擦除、快速形状不会修改它。
2. 在 **0° 基准**上涂选三角形。左键拖动绘制，右键或 Shift + 左键擦除；中键平移，滚轮缩放。“适配视图”让形状回到画面中。
3. 切换 **30° 基准**，单独制作该方向。可以用圆形、前方扇形、直线生成初稿，再手工修改。快速形状只替换当前基准，可撤销。
4. 拖动朝向滑块检查全部 12 个方向。0° 与 30° 可编辑，其他方向只读。黄色十字是单位锚点 `(0,0)`，箭头是面向。
5. 点击“保存资产”，生成或更新 `.asset`；“另存为”创建副本。“导出 JSON”输出完整 12 向规范表；导入后需保存为资产。

单位体积用蓝色，技能范围用橙色。切换配置和关闭窗口时，未保存的资产草稿会提示保存或放弃。导出 JSON 不会清除资产草稿的未保存标记。

新建、“另存为”和“导出 JSON”时，保存对话框按类型默认打开项目已有目录：

| 类型 | 默认目录 |
|---|---|
| 单位体积 | `Assets/Resources/Unit Volume` |
| 技能影响范围 | `Assets/Resources/GeneratedActions` |

可以在对话框中自行更换位置。编辑已有资产时，“保存资产”更新原文件；左侧会显示当前保存位置或新建配置的默认目录。

适配体积引用以 `AttackPattern.AuthoringVolume` 随技能资产保存，重新打开会恢复。旧技能范围若尚无此字段，编辑器会按现有迁移清单中的动作库与体积绑定寻找对应体积，不按文件名猜测；未找到或绑定不唯一时需手动选择。

## 与战斗规则的关系

- 三角形使用现有的整数 `(X,Y,T)` 坐标：`T` 为 `1` 或 `-1`，`X+Y+T` 必须为偶数。
- 0° 和 30° 是两套独立基准，均不能为空。其余方向调用 `DirectionalGeometry.ExpandFromBases` 展开，不会用 0° 自动猜测 30°。
- 单位体积保存为 `UnitVolume`，写入全部 12 向；技能范围保存为 `AttackPattern`，写入两套基准。两者都能由现有 `LegacyGridDefinitionConverter` 转为 Logic 数据。
- 现有单位体积若包含与基准展开不一致的显式方向，载入会报错，不会悄悄覆盖。缺少基准的资产可载入补画。
- 配置 ID 以 `ConfigurationId` 保存在资产中，供 JSON 交换使用。旧资产首次载入优先取迁移清单 ID。
- **新建资产不会自动加入生产战斗目录。** 当前 `BattleDefinitionBuilder` 仍使用 `LegacyIdMigrationManifest` 的显式 GUID / 稳定 ID / 动作与单位绑定。制作完成后，需要由装配端登记引用；现有已登记资产的几何修改沿用原接入路径。JSON 是交换文件，当前运行时不会自动扫描加载它。

## JSON v1

顶层字段为 `version: 1`、`id`、`kind`、`directions`。`kind` 为 `UnitVolume` 或 `AttackPattern`。

技能范围可带可选字段 `referenceVolumeId`，记录适配体积的配置 ID。导入时在项目中查找唯一匹配的单位体积；未找到或 ID 重复时提示重新选择，范围几何仍可导入。旧版不含此字段的 JSON 仍可使用。该引用是制作上下文，不会将单位体积加入攻击格点或改变生产战斗绑定。

`directions` 按 0～11 排列，每项包含整数 `direction` 和 `triangles: [{X,Y,T}, ...]`。三角点按 `(X,Y,T)` 升序且不重复；所有方向都必须与两套基准的整数展开完全一致。导入会拒绝未知版本、空基准、非法点、缺失方向或被单独修改的生成方向，失败时保留当前草稿。

自动化验证位于 `SpatialShapeConfigurationTests`，覆盖 JSON 往返、损坏配置拒绝、写入原子性、现有转换器消费以及现有 10 个技能范围和 3 个单位体积的几何往返。
